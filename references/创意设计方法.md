# 创意设计方法

本文件用于原创生成任务，让服装在第一眼具有惊艳感，同时保持画面结构成立、主题统一、适合人物合成并可继续深化。参考图只用于提炼方法，不复刻具体款式、纹样、配色组合或文案。

## 默认目标

- 用户未明确要求基础、极简、日常或保守款时，默认生成适合成年年轻女性 AI 舞蹈、写真、秀场与角色展示的“高冲击视觉设计款”，而不是只给成熟基础款换颜色、换领口或加一枚蝴蝶结。
- 默认加入可被看见的幻想母题与成年少女感：幻想母题决定世界观和形态，成年少女感决定轻盈度、甜美曲线、年轻色彩和灵动节奏；两者都必须转译成结构与材料，不能停留在形容词。
- 创意来自轮廓、结构、材料、图案落位和动态关系的共同设计，不等于堆砌荷叶边、薄纱、珠饰、流苏或镂空。
- 保留一个容易识别的品类锚点，让人仍能看出它是泳衣、衬衫、西装、裙装或外套；围绕锚点完成明显的新造型主张。
- 每套建立一个强主视觉、一个次级结构变化和一至两个小型呼应点。呼应点共享同一种曲线、折线、方向、材质边界或图案语言，不能互相争抢。

## 创意强度

内部按五级理解，不把级别机械写给用户：

1. 基础耐穿：经典轮廓，仅做精致比例与材质升级。
2. 商品亮点：成熟款式加一个清楚卖点。
3. 设计感：轮廓或结构发生明显变化，仍适合多数商业场景。
4. 惊艳款：默认级别；远看轮廓有辨识度，近看结构、材质和图案形成完整叙事。
5. 概念款：用于先锋、秀场、舞台、艺术服装或用户明确要求大胆实验时。

用户说“简约、基础、日常、保守、通勤”时降到 1–3 级；说“创意、惊艳、吸睛、仙气、华丽、性感、纯欲、甜辣、Cosplay、设计师款、视觉冲击”时保持 4 级；说“先锋、概念、秀场、舞台、超现实”时可升到 5 级。成年安全边界、文化形制、明确要求的运动功能和画面结构稳定性不因强度提升而失效。

## 创意母题与形态语言

先为每套建立一个可视化母题，再设计服装。母题可以来自自然现象、植物生长、动物运动、建筑结构、器物工艺、地貌、光影、海洋、机械或抽象情绪，但不能只写空泛风格词。

从母题中提取两至三种形态语言：

- 线：弧线、放射线、回旋线、断裂线、流线、折线；
- 形：花瓣、翼片、壳层、波纹、晶体、扇面、拱门、鳞片；
- 势：上扬、下坠、环绕、展开、漂浮、收拢、旋转；
- 光：哑光与微光、透明与不透明、冷暖晕染、局部反射；
- 节奏：疏密渐变、长短递进、大小递变、对称中有一处偏移。

领口、袖型、腰线、裙摆、拼片、图案和配件应从同一形态语言发展。不要一处像羽翼、一处像机械、一处又像洛可可，而彼此没有关系。

使用“幻想转译链”检查母题是否真正进入服装：

1. 世界画面：一句具体场景，例如“月光落在开合的蝶翼花园”；
2. 主形态：从场景提取一个远看可见的轮廓动作，例如翼形展开或新月环抱；
3. 中层结构：把相同曲线落实到领口、腰线、裙片或袖型；
4. 近景质感：用两种职责不同的材料和一类高价值装饰表现光线；
5. 动态签名：确定旋转、抬臂或走动时最容易被记住的一条轨迹。

链条少于三层，或只能靠背景、道具和文字解释幻想主题时，重新设计。

## 六类创意引擎

每套选择一个主引擎和一个辅助引擎；同批方案尽量不重复主引擎。

| 创意引擎 | 可用方法 | 必须避免 |
|---|---|---|
| 轮廓变形 | 强肩、翼形袖、披风层、茧形体积、花瓣裙摆、长短错层、局部悬垂 | 全身同时膨胀、没有收束点 |
| 结构重组 | 斜向门襟、环绕裁片、错位腰线、可拆层、翻折结构、内外层互穿 | 悬空部件、无法连接、只写概念不写固定方式 |
| 材料造景 | 透明度渐变、软硬对比、哑光与冷光、压褶与平面、密实与轻纱叠层 | 所有材料都高光、塑料感、材质职责不清 |
| 图案叙事 | 定位纹样、边缘生长、从疏到密、跨裁片延续、留白与重点区域 | 满身平均铺花、纹样遮住结构、照搬专属图腾 |
| 动态塑形 | 垂带、流苏、分层摆片、风琴褶、弧形垂坠、可控展开结构 | 数量失控、左右部件不同步、动势与面料相冲突 |
| 功能转译 | 调节结构外显、模块化罩层、可拆袖、双穿、收纳结构、运动受力线美化 | 为新奇牺牲支撑、防护、活动量或穿脱逻辑 |

传统服饰与文化形制先尊重来源、时代、穿着层次和固定方式，再在允许变化的色彩、材料、纹样尺度、外搭层或展示语言上创新；不要把不相干形制混成泛化“古风”。

## 一套方案的生成顺序

1. 用一句话确定母题和情绪，例如“潮汐退去后留下的弧形水线与贝壳微光”，不要从装饰清单开始。
2. 选一个熟悉的品类锚点，确认视觉用途、身材线条、露肤区域、动作需求和基本穿着结构。
3. 选一个主创意引擎，让它改变远看就能识别的轮廓或结构。
4. 选一个辅助引擎，在领口、腰线、拼片、材料边界或图案落位上呼应主形态。
5. 安排视觉密度：一个高密度焦点区、一个过渡区、足够的安静留白区。
6. 统一色彩、材料和工艺职责，通常使用一个主色域、一个辅助色域和少量高价值点缀。
7. 写清每个特殊部件如何连接、开合、垂坠或随动作运行，删除会漂浮、穿模、遮挡主线条或前后不一致的装饰；不强求默认满足工业量产。

## 批量方案差异

需要 N 套时，内部先形成至少 2N 个候选。最终方案不仅要换品类或配色，还要使用不同的主创意引擎：

- 至少一套由轮廓主导；
- 至少一套由结构、材料或图案叙事主导；
- 四套以上时，至少一套由动态或功能转译主导；
- 不把所有方案都做成大袖、渐变薄纱、层叠裙摆、流苏和刺绣；参考图展现的是完整设计语言的方法，不是固定元素模板。

方案名称应能体现独特母题，避免“甜美款、时尚款、高级款”等空泛命名。

## 创意筛选

先通过成年安全边界、文化识别和画面结构稳定性硬门槛，再按以下方向筛选：

- 第一眼吸引力与原创辨识度：25
- 身材线条、轮廓冲击与比例：20
- 设计语言与主题一致性：15
- 材料、色彩与图案协同：15
- 舞蹈、写真或走秀的镜头动态：15
- 出图、多视图和人物合成稳定性：10

执行四项内部测试：

- **三秒测试**：三秒内能否说出它与常规款最明显的区别；
- **缩略图测试**：忽略小装饰后，轮廓和色块是否仍有辨识度；
- **去装饰测试**：拿掉刺绣、珠饰或印花后，如果只剩普通基础款，则创意不合格；
- **同源测试**：主轮廓、次结构、图案和配件是否像从同一个母题生长出来。
- **幻想脱景测试**：去掉人物、布景和道具后，服装本身是否仍能让人看出幻想世界与成年少女感。

未通过时优先重做轮廓或结构，不用继续增加小装饰掩盖问题。

## 输出要求

- 每套增加 `【创意概念】`，用一至两句写清母题、形态语言和主要创新，不堆抽象形容词。
- `【款式廓形】` 必须写出远看可识别的主轮廓动作；`【结构细节】` 写清辅助创新与连接方式。
- `【配色图案】` 说明图案为什么出现在某一区域以及疏密方向；`【面料质感】` 说明各材料如何帮助主轮廓成立。
- “高级、惊艳、仙气、未来感”等词不能代替具体设计。删除这些词后，方案仍应具有清晰辨识度。
- 不复制现实品牌标志、专属图案或参考图中的独特细节组合，也不默认把任何品类改成新中式或幻想古装。
