# 展示与输出规范

本文件是提示词格式、视图、摄影棚展示、图片反推和结构约束的唯一权威来源。目标是让结果便于比较和复制，并让服装成图真实、完整、适合后续人物合成。

## 输出原则与字段

- 默认使用 Markdown，不输出 JSON；用户明确要求 JSON、YAML、纯表格或纯自然段时再切换。
- 通常多方案使用“一张总览表＋统一方案卡＋一行后续操作”；单方案省略总览。方案卡中的带标签文本就是完整可复制提示词，不再重复同义拆解。
- 通常交付在整份输出末尾保留一行后续操作，整份只出现一次，包含“做成部件拆解板”；用户只要提示词、指定数据格式或禁止附加说明时省略此行。该例外适用于原创、精修、连续修改与图片反推。
- 每套脱离上下文仍完整，不写“同上、同款、延续前述”；反向约束放在各自方案内。
- 新原创方案依次包含：`【创意概念】`、`【款式廓形】`、`【结构细节】`、`【配色图案】`、`【面料质感】`、动态专业维度、`【镜头动态】`、`【展示构图】`、`【反向约束】`；创意概念写出母题与主／辅助引擎名称。精修或保留已有方案沿用原格式；仅有短摘要时可用自足自然段保留已知信息，不为凑九字段新增母题、材质或结构，不宣称复现未提供的完整原稿。
- **华丽方向（默认）的字段落地要求**：结构细节写清层次与已有部件数量，配色图案写清实际纹样与配色比例，面料质感写清主辅材料分工；单色可写 100%，无纹样、无透光层时不强加。具体视觉强度按 [创意与审美规范](创意与审美规范.md) 的品类规则检查。
- 原创方案按「展示构图：固定底座 ＋ 可变版式」选取适用版式，在各套中写明版式、背景与画幅；多样化服从设计内容与用户构图要求，不要求版式互不重复。
- 方案标题下可用一句“核心卖点”帮助浏览；卖点必须具体，不只写高级、时尚或爆款。

动态专业维度只选一个主字段：

| 品类 | 字段 | 内容 |
|---|---|---|
| 泳装、内衣 | 覆盖与支撑 | 覆盖度、胸部固定、肩带与下围受力、裆部和腿口 |
| 运动服 | 运动功能 | 运动类型、强度、排汗、弹力、接缝与关节活动量 |
| 户外服 | 防护性能 | 温度、天气、防风防水、透气、保温与调节结构 |
| 外套 | 穿着层次 | 内搭容量、保暖、开合、防风与叠穿关系 |
| 西装、通勤装 | 正式程度 | 场合、肩部、驳领、裤褶、面料与内搭 |
| 礼服、婚纱 | 礼仪等级 | 正式度、支撑、垂坠、拖尾与行动便利性 |
| 传统服饰 | 形制与文化 | 来源、时代、成套部件、层次、系结与纹样位置 |
| 家居服、睡衣 | 舒适性能 | 亲肤、松量、接缝、开合、保暖或透气 |
| 日常单品 | 穿着体验 | 活动量、口袋、开合、内搭、季节和搭配性 |
| 完整穿搭 | 搭配层次 | 内外顺序、上下比例、鞋包配饰和视觉重心 |

## 展示构图：固定底座 ＋ 可变版式

用户未指定展示方式时，原创 `【展示构图】` 由**填好的底座模板 + 一种适用版式 + 画幅**组成。人物上身、场景、双视图、三视图与部件拆解板按用户要求或对应章节组织，不叠加互相冲突的默认模板。

### 固定底座（按任务填充，交付时不保留占位符）

```text
服装以自然穿着形态悬浮陈列，具备{对象比例}，以服装自身容量撑起真实穿着形态与重力垂坠，不由可见形体支撑；画面中不出现真人、人台、头部、面部、肢体与皮肤，无衣架；{背景与光线}；四周留白、完整不裁边，只展示本套服装，无无关主体与意外重复；{视图安排}。
```

- `{对象比例}`：默认成年女款的肩胸腰胯比例；男款、中性或其他明确对象按其版型替换。反推按服装可见廓形与容量，不推断人物身份、年龄或身材。
- `{背景与光线}`：默认纯白无缝底、5500K 冷中性柔光与自然软阴影，排除偏黄底；珍珠浅灰护边或用户指定背景替换整段，不同时保留白底。用户指定光线或暖色背景时不追加相反的色温、底色排除项。
- `{视图安排}`：默认完整正面；D 版式允许同款一处局部特写，双视图／三视图使用对应视角与同款重复。真人上身时改写整个陈列与人物状态段，人物穿着的鞋袜不沿用空置陈列要求；明确场景时替换摄影棚段。正向描述与反向约束必须同步，不能同时要求与禁止同一对象。

### 版式池（从适用版式中优先多样化；**仅用于原创生成**）

**本节只适用于原创生成的 `【展示构图】`。图片反推的 `【陈列构图】` 不参与版式轮换**——反推以忠实还原为主，只沿用下面的固定底座与默认浅色背景，规则见 §图片反推。

| 版式 | 构图骨架 | 建议画幅 |
|---|---|---|
| A 单件居中 | 一件主品居中悬浮，完整正面 | 竖版 |
| B 上下分离 | 上装与下装分开悬浮、上下排布，各留净距 | 竖版 |
| C 整套穿着 | 按穿着顺序组合成一体（内搭在内、外套在外、下装在下），保持叠压与重力关系 | 竖版 |
| D 主图＋局部特写 | 主图居中，另附一处局部放大（领口、腰封、刺绣或五金），以引线或留白分隔 | 竖版或方版 |
| E 主件＋可拆件 | 主件居中，可拆配件（披帛、腰封、纱袖、腰链）分列旁侧，各留净距 | 竖版或横版 |

- 内容适用且用户未统一指定构图时，优先选择不同版式；单品、适用版式不足或方案数超过版式池容量时允许重复。不得为了换版式添加下装、配件、可拆层或改变设计；用户指定统一展示时全部遵守。
- **选取倾向**：成套造型（上下装加配饰组成的一整套）**默认优先 C 整套穿着**——它最接近「一整套造型」的整体观感。同批需要差异时再按内容改选：单件主品（长裙、外套、单件礼服）用 A 单件居中；上下装分体且需分别交代时用 B 上下分离；五金、刺绣、领口等细节本身是卖点且需放大时用 D。
- **E 主件＋可拆件只在「可拆配件本身是核心卖点」时使用**（例如可拆腰封、披帛、纱袖的连接关系就是设计重点）。否则拆件分列会削弱整体感，让画面接近商品平铺目录——实测中把一套泳装拆成「主件＋旁侧罩衫」后，观感明显不如整套穿着。
- 版式与画幅按内容决定，不固定搭配；背景与用户条件一致。同批可重复适用组合，方案差异主要由服装设计体现。
- 版式 D 的局部特写必须写明放大部位；除版式 D 外，禁止分栏、拼图、画中画与局部插图。

### 背景选择（默认固定纯白摄影棚）

**默认固定使用纯白无缝摄影棚背景，不因风格变化**：色温中性（约 5500K）、色相不带黄的冷中性白底板，配柔和漫射光、自然软阴影与轻微接触阴影。华丽、幻想、古风、舞台与 Cosplay 同样优先浅底——**华丽感由服装本身承担**。

- **底色色相必须锁死**：只写"纯白"不足以约束，必须同时写明禁止替换物——**禁止米黄、奶油黄、蛋壳色、暖黄、做旧泛黄、香槟暖白等一切偏黄底色**；底板不得单独偏蓝或偏红，须为冷中性白。原理同 §结构与反向约束 的「易误读术语必须补排除」：名称在生图模型中有更常见的对应物时，须写出正确形态与禁止替换物。
- **唯一例外——护边改用珍珠浅灰**：仅当服装本身为白色、粉彩、珠光或半透明、在纯白底上边缘会糊掉时，才改用**珍珠浅灰**，并仍须满足上面的暖调排除要求。这是唯一允许的替换，**米白与极浅暖灰已从默认池移除**，不得再作为默认底色使用。
- 深色服装用纯白底并靠轮廓光分离结构，避免糊成一片。
- **深底只在用户明确要求时使用**（例如"换黑底""要舞台感"）：用近黑或深灰无缝底板，以轮廓光勾勒边缘，**不配场景、道具、烟雾与霓虹**。
- 用户明确指定背景时以用户为准。
- **白平衡与底色必须指向同一色相**：不再使用"中性白平衡"这类抽象表述——它与暖调底色会互相拉扯，模型会优先服从底色。改写为可执行的光线描述：**色温 5500K 冷中性白、无暖色环境光染色**，并把底色排除项（禁止米黄、奶油黄、暖黄、做旧泛黄）同时写入 `【反向约束】`。
- 表现真实纤维纹理、合理厚薄、重力垂坠、缝线、包边、褶皱根部、层间接触和克制反光；避免全套自发光、过曝描边、塑料宝石、乳胶壳、游戏建模和失重感。
- **默认展示形态是「自然穿着形态悬浮陈列」**：服装具备与对象版型相符的肩胸腰胯容量，以撑起穿着形态与重力垂坠；默认成年女款，其他对象按底座模板替换，不能把男款强制塑成女性胸腰。
- **同时不允许出现可见形体**：不出现人台、人体、头部、面部、手臂、腿部、脚与任何皮肤。**比例由服装的穿着容量体现，不由可见的人台体现。** 露出生硬的人台、尤其带腿脚的整身模特，同样判为不达标。
- 排除项：真实人物、人台、头部、面部、手臂、腿部、脚与任何皮肤；衣架；黑洞领口、残肢断面、僵硬球壳、纸片平铺，以及**缺乏统一重力方向、布料无垂坠、无接触阴影的失重感**。
- 人体依赖单品（连裤袜、袜子、鞋靴、手套）与扁平配饰按空置平铺、轻折或成对摆放处理。
- 用户明确要求真人上身、模特、舞蹈人物、写真或走秀时，才切换为 18 岁以上成年人物，并写清姿态、机位和服装动态。

## 双视图、三视图与设计稿

用户说“双视图、二视图、正背双视图”时，`【展示构图】` 必须表达：

```text
一张横向左右双栏服装展示板，左栏完整正面，右栏同款完整背面；两栏等宽、同尺度、同高度、同基线、同背景、同光线，服装均以自然穿着形态悬浮陈列（同尺度人体比例、不出现可见人台与人体），以留白分隔，无衣架，四周留白、完整不裁边。
```

- 用户明确指定“左背右正”等相反顺序时才调整，否则始终左正右背。
- 两栏的款式、配色、材料、图案尺度、包边、系带、珠饰和成套件数一致；前后专属结构位置正确，侧缝、肩带、腰线和图案连接合理。
- 默认不添加“正面／背面”文字、箭头、编号或尺寸线。反向约束排除顺序颠倒、双正面、双背面、单栏缺失、重叠、前后不一致、比例不同、细节错位和裁边。
- “两套”仅表示方案数量，不能触发双视图。
- 输入“设计稿、款式图”但未写视图数量时仍为正面视角，版式按版式池选择；只有明确要求“三视图、正侧背三视图”时才生成正面、侧面、背面三栏，并保持同款一致。

## 部件拆解板

用户明确要求“部件拆解板、拆件板、服装资产板、把整套拆成可单独截图的部件”时使用本版式；未要求时按「展示构图：固定底座 ＋ 可变版式」一节的版式池选择。

```text
一张横向 3:2 服装部件拆解板，浅中性灰无缝摄影棚背景（冷中性、色相不带黄，禁止米黄／奶油黄／暖黄／做旧泛黄），柔和漫射光、色温 5500K 冷中性白、无暖色环境光染色，无人物、无衣架，四周留白、完整不裁边。左侧约 38% 为完整整套穿搭的正面陈列，以自然穿着形态悬浮陈列（具备人体比例、不出现可见人台与人体）；右侧约 62% 按实际部件分格，每件正面、独立完整。底部仅在确有价值时设细节带（五金、绣样、绑带或纹样），可占右侧各栏的底部宽度，不强制整宽；无价值则留白。每件编号并标一个短中文名称，标签小且清晰。
```

- 拆件顺序按穿着层次，且配饰紧随其关联主衣物：上衣或外套 → 内搭 → 颈肩配饰（领结、领带、围巾、胸针）→ 下装及其腰带腰饰 → 人体依赖单品（连裤袜、袜子、鞋靴）→ 包袋与其他配饰。不要把所有配饰一律压到最后一格。
- 人体依赖单品必须进入拆件格，不得因“无人物”而省略；连裤袜保持完整空置结构，鞋靴保持空置鞋腔。
- 每格只出现该件衣物，不得混入其他衣物的袖口、下摆或垂布；单列上衣不重复带外套垂袖。
- 背面仅在参考图或用户说明明确存在有辨识价值的背面设计（背部印花、露背、交叉绑带、特殊后片）时才展示；普通素背默认不展示，不为凑齐视角推测特殊设计。
- 反向约束排除：分栏错位、重复衣物、两件衣物同格、部件被裁边、编号缺失或不可读、人体或隐形人台、衣架、标签遮挡部件、以及参考图中不存在的虚构部件。
- 标签用于检索，不替代画面；不让解释文字占据版面。留白优于为填格增加假部件。

```text

## 穿搭拆解

三级标注贯穿以下各项，不止于单独一节：**可见**照写，**合理补全**注明是推定，**不可确认**不写成事实。

- 单品层次：按穿着顺序列出可见主衣物、由局部证据支持的内搭、人体依赖单品与配饰；衣身被遮挡不等于该层不存在。
- 轮廓比例：长度、松量、腰线和上下装关系。参考图仅有正面时，背面相关比例标为不可确认。
- 配色图案：可见主辅色、图案与落位；被遮挡处的图案延伸标为推定。
- 面料质感：只写合理可见的观感，不断言不可见成分。
- 不可确认项：纤维成分、里层结构、被遮挡结构、开合方式等，集中列在末尾，不混入上述事实性描述。

【款式廓形】……
【结构层次】……
【配色图案】……
【面料质感】……
【人体依赖单品】……（仅在存在连裤袜、袜子、鞋靴或手套时输出）
【配饰与鞋包】……（包袋、帽饰发饰、首饰、腰带、围巾披肩；无则省略）
【陈列构图】……
【反向约束】……
```

- 忠实保留可见品类、局部证据、层次、主色、轮廓和主要细节；分别说明画面可见数量与成套陈列所需的推定数量。不描述人物身份、外貌、身材评价，不臆造被遮挡的背面、开合、图案或配饰。
- **局部可见的内搭**：外衣下露出独立细肩带、领边或袖口时，该层须进入穿搭拆解和可复制提示词，不得只在“不可确认项”里提一句。可见部分照写；若主体被遮挡，成图以纯色、无额外装饰的最简完整内搭独立展示，并在文字中标明“依据局部证据推定”。仅见肩带时不判定为吊带衫或文胸的确定款式，也不虚构罩杯、下摆或背面细节；有证据表明它属于外衣本身或配饰时不另加内搭。
- **单侧可见的成对单品**：一只袜子、鞋或手套入镜且没有单只、混穿或不对称证据时，穿搭拆解写明“一侧可见、另一侧推定同款”；可复制提示词与成图陈列完整一双或一副。用户明确要求只展示画面确证部分时才只陈列可见的一侧。此规则不允许补出图中未见品类，例如只见袜子就添加鞋子。
- `【配饰与鞋包】` 与 `【人体依赖单品】` 分工明确：穿着时依赖人体的鞋靴、袜类、手套进人体依赖单品；可独立陈列的包袋、帽饰发饰、首饰、腰带、围巾披肩进配饰与鞋包。两者按可见件数及有依据的成套补全件数输出，无则省略该字段。
- 三级标注是反推的默认交付形式：可见项照写；成图需要的合理补全可进入可复制提示词，但须带“推定”及最简结构，不写成图中可见的事实；没有证据支持的细节列为不可确认，不进入提示词的肯定表述。
- 直接出图前核对同一份完整单品清单：局部可见内搭是否展示、成对单品是否补齐、推定是否保持最简，以及未见鞋包等是否未被添加。不得在文字提取正确后，成图又漏件或只画单侧。
- 通常结尾保留一行后续操作，动作面向反推场景；省略例外见 §输出原则与字段。反推只返回 1 套，不得照抄多方案里的“重抽第 N 套”；纯提示词请求只交付可复制提示词，三级证据标注仍保留在相关字段内。
- 输出前检查术语与字段一致：短袖不能同时写七分袖；连裤袜使用腰口、裤身、裆部、袜腿、袜尖，不写“裤脚”；长度、件数、开合和图案方向前后不矛盾；鞋袜与配饰术语按 [鞋袜与配饰库](鞋袜与配饰库.md) 校准。
- `【陈列构图】` 沿用填好的底座模板与默认背景，**不使用版式池**：反推默认整套正面陈列，不标注「版式 A／B／C／D／E」、不自行指定画幅。服装比例按可见廓形；用户明确要求背景、画幅、人物上身或多视图时按其要求替换对应描述，未指定时保持反推默认。

### 人体依赖单品

- 连裤袜、长短袜、鞋靴和手套必须保留，但与主衣物分离为空置平铺、轻折或成对摆放，并与裙摆、裤口和袖口留出清楚间距。
- 连裤袜完整展示腰口、裤身、裆部、两条松弛袜腿和袜尖，不从裙摆向下延伸，不出现膝盖、腿肚、脚踝、脚掌或脚趾轮廓。
- 长短袜左右成对、内部为空；即使参考图只露出一只，默认也按上面的成对补全规则陈列一双。鞋靴保持空置鞋腔，不补画脚背和脚；手套柔软空置，不出现皮肤、指甲、掌纹或被隐形手撑开的姿态。
- 反向约束明确排除人体、隐形肢体、假肢、模特腿、膝盖、小腿肌肉、脚踝、脚掌、脚趾、手掌、皮肤以及被人体撑起的单品。

## 结构与反向约束

- 只写品类相关结构，说明前后片、侧缝、腰口、裆部、腿口、肩带、袖窿、罩杯、衬里、门襟、系带和可拆部件的真实连接；成对部件数量、位置、长度和末端处理一致。
- 多视图中同款的颜色、结构、纹样、透明区和配件保持一致，前后专属细节不复制、错位或消失。
- 每套 `【反向约束】` 优先排除其最可能发生的错误，并按需覆盖：缺件、重复、左右不对称、纽扣或珠饰数量混乱、拉链中断、绑带无连接点、袖身脱离、前后片不接、衬里外翻、裆部腿口错误、图案断裂、透明区错位。
- **易误读术语必须补排除**：当结构或纹样的名称在生图模型中存在更常见的对应物时，**不能只写名称**，要在该套 `【反向约束】` 中同时写出**正确形态**与**禁止替换物**。实测连续两轮出图中——「前中扭结」均被渲染成**大蝴蝶结**、「糖晶涟漪」定位纹样被渲染成**扎染色块**。常见对照：扭结／打结→蝴蝶结或巨大装饰结；等宽细线定位纹→扎染或晕染色块；抽褶→荷叶边；罗纹收口→松紧边；扇骨切口→锯齿；流苏→羽毛。
- 材质反向约束按需排除：塑料感、充气感、过度金属化、全身发光、布料厚度失真、无重力、过曝和游戏建模。
- 构图反向约束按视图需求排除：裁边、遮挡、无关配件、文字、品牌标志、水印、背景杂物以及未请求的多角度、分栏、重复主体、拼图、画中画和局部放大。

## 输出前检查

- 总览能否快速区分方案，字段顺序是否一致且没有换词重复；
- 创意概念、专业维度和镜头动态是否具体并适配品类；
- 任一方案单独复制后，主体、结构、材料、展示和反向约束是否完整；
- 版式、画幅、背景与人物状态是否严格遵守用户要求；未要求时不得出现分栏、拼图或部件拆解板（版式 D 的局部特写除外）；
- 原创所选版式是否适合内容，是否为换版式增添单品；允许重复适用版式，用户统一构图时是否全部一致。每套所需背景、画幅与视图是否写清，底座占位符已替换，人物状态与反向约束是否一致；
- 默认摄影棚是否写清冷中性白与 5500K，排除偏黄底；用户指定背景或光线时是否已替换相反的默认排除项；
- 原创未指定展示方式的成套造型是否优先考虑 C；若用 E，可拆配件是否是核心卖点，未为凑版式差异拆件；
- 含易误读术语（扭结、定位线纹、抽褶等）的方案，`【反向约束】` 是否写出了正确形态与禁止替换物；
- 默认无人物陈列是否保持对象版型容量与空置鞋袜；明确人物上身时，穿着、姿态与反向约束是否一致，未保留禁止人体或袜鞋空置要求；
- 反推是否已按可见、合理补全、不可确认三级标注，且推定项未写成事实；
- 反推图中若只露出内搭的一小部分或一只袜鞋手套，是否在提示词与成图中保留内搭层、按证据补齐成对件，并明确推定与可见的区别；
- `【配饰与鞋包】` 与 `【人体依赖单品】` 是否分工正确、无重复无遗漏；
- 原创材质是否具体到结构与物理表现；反推是否只保留有证据的材质观感，未将不可确认纤维或织法写成事实；
- Markdown 标题、表格和空行是否正常渲染；
- 通常交付的后续操作行是否只在末尾出现一次；纯提示词或禁止附加说明等请求是否按规则省略。
