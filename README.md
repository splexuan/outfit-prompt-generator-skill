# 穿搭提示词生成器（Outfit Prompt Generator）

一个以 **18 岁以上年轻女性 AI 视觉服装** 为核心的中文提示词技能。它把简短品类、穿搭需求和已有设计扩展为适合舞蹈视频、写真、身材展示、时装秀、舞台、Cosplay、仙侠与唯美古风的吸睛服装方案，也能从人物参考图反推出可复用的穿搭描述。

## 功能

- 短品类输入默认固定生成 3 套差异明显的原创方案
- 未指定性别时统一按 18 岁以上成年年轻女款生成，明确指定男款、中性或混合方向时按用户要求执行
- 默认采用 AI 视觉展示模式，以第一眼吸引力、身材比例、幻想母题、成年少女感和镜头动态为最高优先级；日常、竞技与量产仅在明确要求时切换
- 默认幻想浓度为 4／5，通过“世界画面—大轮廓—中层结构—近景材质—动态签名”把月光、蝶翼、海洋、花园、云雾、糖霜、暗夜或未来精灵等母题真正变成服装
- 少女感定义为成年女性的轻盈、甜美、灵动和浪漫审美，并以成熟合体比例平衡；不会转写成儿童或幼态性化设计
- 默认恢复白色、米白、珍珠浅灰或极浅暖灰无缝摄影棚展示：无人物、无衣架、保持自然穿着容量，便于后续与成年人物合成；黑底和幻想场景只在明确要求时使用
- 未指定视图数量时固定生成一个居中的完整正面单一视图；双视图、三视图、多角度、分栏或拼图必须由用户明确触发，默认 3 套不会合并成一张三栏图
- 使用中性白平衡、柔和漫射光、自然软阴影以及真实布料厚度、重力垂坠、缝线和层间接触，避免发光塑料、游戏建模、僵硬空壳和无重力漂浮
- 多方案先给横向总览表，再用统一字段输出可直接复制的方案卡，便于快速比较
- 根据品类自动切换专业维度，例如泳装的覆盖与支撑、运动服的运动功能、外套的穿着层次
- 支持“双视图／二视图”构图，固定左栏正面、右栏背面，并保持前后结构一致
- 默认生成适合镜头的惊艳设计款，用创意母题、六类创意引擎、视觉复杂度下限和同源呼应系统避免基础款微调
- 每套增加“镜头动态”，说明后续人物视频中的身材线条、舞蹈或走秀部件轨迹，同时明确不改变本次单一正面服装视图
- 成年女性只输入“泳衣”时默认生成二至四件的视觉度假套装，不再优先返回朴素运动连体；竞技或训练方向需明确指定
- 支持性感、可爱、纯欲、甜辣、华丽和大胆露肤的成年时尚，也明确排除未成年人或幼态角色的性化设计
- 支持女装、男装、泳装、内衣、运动、礼服与明确形制的传统服饰
- 支持商品图、完整穿搭、设计稿、正背面、三视图和提示词精修
- 上传人物图后，可反推图中可见服装、层次、配色、材质与配饰关系
- 反推结果含连裤袜、袜子、鞋靴或手套时，会保留这些单品并与主衣物分离为空置陈列，避免出现不合理的隐形腿、脚趾或手部轮廓
- 支持连续修改，例如“保留第 2 套并重抽其余”“全部改成高腰”或“直接生成第 2 套图片”

## 目录结构

```text
outfit-prompt-generator/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── 女装款式库.md
    ├── 男装款式库.md
    ├── 专项服饰库.md
    ├── 通用设计元素库.md
    ├── 创意与审美规范.md
    ├── 展示与输出规范.md
    └── 测试用例.md
```

`SKILL.md` 是精简的技能入口；品类词库、创意审美、展示输出和测试分别按需读取，普通任务不会加载无关资料。`agents/openai.yaml` 是可选的产品界面元数据，不支持该格式的智能体可以忽略它。

## 通用安装

### 方法一：安装到智能体的技能目录

先在你的智能体文档或设置中找到技能目录，以下统一记作 `<AGENT_SKILLS_DIR>`。克隆仓库：

```bash
git clone https://github.com/splexuan/outfit-prompt-generator-skill.git <AGENT_SKILLS_DIR>/outfit-prompt-generator
```

安装后的关键路径应为：

```text
<AGENT_SKILLS_DIR>/outfit-prompt-generator/SKILL.md
```

重启智能体或刷新技能列表。如果平台支持项目级和用户级技能目录，可按需要选择；项目级仅对当前项目生效，用户级通常对全部会话生效。

### 方法二：手动复制

下载仓库 ZIP，解压后将整个目录复制到智能体的技能目录。不要只复制 `SKILL.md`，否则智能体无法读取 `references/` 中的款式库与质量规则。

### 方法三：没有技能系统的智能体

将 `SKILL.md` 作为系统提示、自定义指令或任务上下文提供给智能体，并同时上传 `references/` 目录。要求智能体以 `SKILL.md` 为入口，按其中的“读取参考文件”规则选择所需资料。

人物图片反推还要求智能体具备图片理解能力；直接生成图片则需要智能体连接任意可用的图像生成工具。技能本身不绑定特定模型或图像平台。

## 使用

支持显式技能调用的平台可以这样输入：

```text
$outfit-prompt-generator 夏日泳装
```

不支持技能名称调用的平台，直接描述需求即可：

```text
粉色系泳衣｜舞蹈视频｜详细版
```

未指定性别时会默认女款。指定其他方向时写明即可：

```text
男款｜春季通勤｜3套｜海军蓝
```

上传人物图后可以输入：

```text
反推这张图里的穿搭提示词
```

技能会只提取有视觉依据的服装信息，并将结果整理为无人物、无衣架的完整穿搭陈列提示词。

常见连续操作：

```text
扩写第 2 套
保留第 2 套并重抽其余
全部改成高腰
减少装饰，提高覆盖度
直接生成第 2 套图片
```

## 验证安装

输入 `夏日泳装`，正常结果应满足：

- 固定返回 3 套女款方案；
- 三套均为成年女性视觉度假造型，并在款式、配色、材质和动态上有明显差异；
- 每套提示词可独立复制；
- 首先出现方案总览表，每套按统一字段排列，使用“覆盖与支撑”作为泳装专业维度，并包含“镜头动态”；
- 默认展示约束包含“无人物、无衣架”；
- 未指定视图时，每套都是一个完整正面单一视图，并排除三视图、正侧背并列、重复主体和拼图；
- 默认不是朴素运动连体，而是泳装主体加一至两件可拆视觉层；
- 默认采用白色或浅色摄影棚背景，以柔和光线和自然软阴影避免浅色服装过曝、深色服装丢失结构；
- 结尾提供简短的继续修改方式。
