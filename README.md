# 穿搭提示词生成器（Outfit Prompt Generator）

一个以 **18 岁以上年轻女性 AI 视觉服装** 为核心的中文提示词技能。它把简短品类、穿搭需求和已有设计扩展为适合舞蹈视频、写真、身材展示、时装秀、舞台、Cosplay、仙侠与唯美古风的吸睛服装方案，也能从人物参考图反推出可复用的穿搭描述。

## 功能

- **服务于 AI 视频与图像创作，不是日常穿搭工具**：首要标准是**看上去就美**，艺术性、华丽度与镜头冲击优先于实穿性与日常得体度
- 未指定数量时默认固定生成 3 套差异明显的原创方案，不区分输入是短关键词还是完整描述句
- 未指定性别时统一按 18 岁以上成年年轻女款生成，明确指定男款、中性或混合方向时按用户要求执行
- 默认采用 AI 视觉展示模式，以第一眼吸引力、身材比例、幻想母题、成年少女感和镜头动态为最高优先级；日常、竞技与量产仅在明确要求时切换
- **默认装饰层级为高：未明确要求简约时一律走华丽繁复方向**——多层叠穿、渐变染色、成套纹样、金银织线、流苏长穗、腰封收束等手段默认启用；只有明确要求基础、日常、通勤、保守、实穿或简约时才降级（规则见 `references/创意与审美规范.md` 的「华丽与结构化繁复」）
- 默认创意强度为 4／5（定义见 `references/创意与审美规范.md`），通过“世界画面—大轮廓—中层结构—近景材质—动态签名”把月光、蝶翼、海洋、花园、云雾、糖霜、暗夜或未来精灵等母题真正变成服装
- 少女感定义为成年女性的轻盈、甜美、灵动和浪漫审美，并以成熟合体比例平衡；不会转写成儿童或幼态性化设计
- 主衣物以**自然穿着形态悬浮陈列**（具备肩线、胸围、收腰、胯宽的人体比例，但画面中**不出现任何人台、人体与皮肤**），人体依赖单品空置平铺
- **展示构图为「固定底座 ＋ 可变版式」**：从五种版式（单件居中／上下分离／整套穿着／主图＋局部特写／主件＋可拆件）中选取，**同一批 3 套不得重复版式**，避免每张图版式雷同；成套造型默认优先「整套穿着」，拆件分列只在可拆配件本身是卖点时使用
- **背景固定为纯白无缝摄影棚**（色温 5500K 冷中性白、色相不带黄，禁止米黄／奶油黄／暖黄／做旧泛黄；仅当服装为白色、粉彩、珠光或半透明需护边时改用珍珠浅灰），不因风格变化——华丽感由服装本身承担；深底或场景背景只在用户明确要求时使用
- 未指定视图数量时，每套按版式池自行选定版式与画幅并在提示词中写明，同一批 3 套不得重复；双视图、三视图、多角度、分栏或拼图必须由用户明确触发，默认 3 套不会合并成一张三栏图
- 使用冷中性白光、柔和漫射光、自然软阴影以及真实布料厚度、重力垂坠、缝线和层间接触，避免发光塑料、游戏建模、僵硬空壳和失重感
- 多方案先给横向总览表，再用统一字段输出可直接复制的方案卡，便于快速比较
- 根据品类自动切换专业维度，例如泳装的覆盖与支撑、运动服的运动功能、外套的穿着层次
- 支持“双视图／二视图”构图，固定左栏正面、右栏背面，并保持前后结构一致
- 默认生成适合镜头的惊艳设计款，用创意母题、六类创意引擎、视觉复杂度下限和同源呼应系统避免基础款微调
- 每套增加“镜头动态”，说明后续人物视频中的身材线条、舞蹈或走秀部件轨迹，同时明确不改变本次服装成图已选定的版式与画幅
- 成年女性只输入“泳衣”时默认生成二至四件的视觉度假套装，不再优先返回朴素运动连体；竞技或训练方向需明确指定
- 支持性感、可爱、纯欲、甜辣、华丽和大胆露肤的成年时尚，也明确排除未成年人或幼态角色的性化设计
- 支持女装、男装、泳装、内衣、运动、礼服与明确形制的传统服饰
- 支持商品图、完整穿搭、设计稿、正背面、三视图和提示词精修
- 上传人物图后，可反推图中可见服装、层次、配色、材质与配饰关系
- 反推结果含连裤袜、袜子、鞋靴或手套时，会保留这些单品并与主衣物分离为空置陈列，避免出现不合理的隐形腿、脚趾或手部轮廓
- 支持连续修改，例如“保留第 2 套并重抽其余”“全部改成高腰”或“直接生成第 2 套图片”
- 支持“部件拆解板”版式，把整套拆成可单独截图的编号部件，便于换装与跨套混搭（说“把这套衣服做成部件拆解板”即可触发）
- 反推结果按“可见／合理补全／不可确认”三级标注逐件交付，推定项不写成事实
- 明确 Cosplay 只做风格转译，不 1:1 还原版权角色服装
- 鞋袜、包袋、帽饰、首饰等配饰术语由 `references/鞋袜与配饰库.md` 校准
- 指定图像平台时按 `references/平台适配.md` 调整语言形态，不杜撰平台参数

## 目录结构

```text
outfit-prompt-generator/
├── SKILL.md
├── CHANGELOG.md
├── agents/
│   └── openai.yaml
└── references/
    ├── 女装款式库.md
    ├── 男装款式库.md
    ├── 专项服饰库.md
    ├── 通用设计元素库.md
    ├── 鞋袜与配饰库.md
    ├── 创意与审美规范.md
    ├── 展示与输出规范.md
    ├── 平台适配.md
    └── 测试用例.md
```

`SKILL.md` 是精简的技能入口；品类词库、鞋袜配饰、创意审美、展示输出、平台适配和测试分别按需读取，普通任务不会加载无关资料。`agents/openai.yaml` 是可选的产品界面元数据，不支持该格式的智能体可以忽略它。

## 通用安装

### 方法一：安装到智能体的技能目录

先在你的智能体文档或设置中找到技能目录，以下统一记作 `<AGENT_SKILLS_DIR>`。克隆仓库：

```bash
git clone https://github.com/splexuan/outfit-prompt-generator-skill.git <AGENT_SKILLS_DIR>/outfit-prompt-generator
```

安装后的关键路径应为：

```text
<AGENT_SKILLS_DIR>/outfit-prompt-generator/SKILL.md
```

重启智能体或刷新技能列表。如果平台支持项目级和用户级技能目录，可按需要选择；项目级仅对当前项目生效，用户级通常对全部会话生效。

### 方法二：手动复制

下载仓库 ZIP，解压后将整个目录复制到智能体的技能目录。不要只复制 `SKILL.md`，否则智能体无法读取 `references/` 中的款式库与质量规则。

### 方法三：没有技能系统的智能体

将 `SKILL.md` 作为系统提示、自定义指令或任务上下文提供给智能体，并同时上传 `references/` 目录。要求智能体以 `SKILL.md` 为入口，按其中的“读取参考文件”规则选择所需资料。

人物图片反推还要求智能体具备图片理解能力；直接生成图片则需要智能体连接任意可用的图像生成工具。技能本身不绑定特定模型或图像平台。

## 使用

支持显式技能调用的平台可以这样输入：

```text
$outfit-prompt-generator 夏日泳装
```

不支持技能名称调用的平台，直接描述需求即可：

```text
粉色系泳衣｜舞蹈视频｜详细版
```

未指定性别时会默认女款。指定其他方向时写明即可：

```text
男款｜春季通勤｜3套｜海军蓝
```

需要把整套拆成可单独截图的部件时：

```text
把这套衣服做成部件拆解板
```

上传人物图后可以输入：

```text
反推这张图里的穿搭提示词
```

技能会只提取有视觉依据的服装信息，并将结果整理为无人物、无衣架的完整穿搭陈列提示词。

常见连续操作：

```text
扩写第 2 套
保留第 2 套并重抽其余
全部改成高腰
减少装饰，提高覆盖度
直接生成第 2 套图片
把这套（或第 2 套）做成部件拆解板
反推结果直接生成成图
```

## 验证安装

输入 `夏日泳装`，正常结果应满足：

- 固定返回 3 套女款方案；
- 三套均为成年女性视觉度假造型，并在款式、配色、材质和动态上有明显差异；
- 每套提示词可独立复制；
- 首先出现方案总览表，每套按统一字段排列，使用“覆盖与支撑”作为泳装专业维度，并包含“镜头动态”；
- 默认展示约束包含“无人物、无衣架”；
- 未指定视图时，每套按版式池选定版式并写明版式与画幅，并排除三视图、正侧背并列、重复主体和拼图；
- 默认不是朴素运动连体，而是泳装主体加一至两件可拆视觉层；
- 默认使用纯白无缝摄影棚背景（色温 5500K 冷中性白，禁止偏黄底色），并以柔和光线与自然软阴影避免浅色服装过曝、深色服装丢失结构；深底只在用户明确要求时使用；
- 结尾（整份输出最末尾一次）提供简短的继续修改方式，且包含“做成部件拆解板”入口。
