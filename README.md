# 穿搭提示词生成器（Outfit Prompt Generator）

把服装关键词、设计要求或人物参考图，转成可直接复制的服装提示词。适用于 AI 舞蹈视频、写真、时装秀、Cosplay 和幻想古风造型，默认为成年女性设计华丽、吸睛的服装。

## 能做什么

- **原创设计**：生成不同款式，写清结构、配色、材质与展示方式。
- **图片反推**：提取可见穿搭，默认给出整套陈列版和部件拆解版两版提示词，区分已知信息与推定细节。
- **修改与拆解**：精修已有方案，制作正背视图或可单独截图的部件拆解板。

## 快速开始

支持技能名称调用的平台可以输入：

```text
$outfit-prompt-generator 粉色系泳衣
```

也可以直接描述需求：

| 想做什么 | 输入示例 |
|---|---|
| 指定条件 | 男款，春季通勤，3 套，海军蓝 |
| 反推穿搭 | 上传人物图后：反推这张图里的穿搭提示词 |
| 修改某套 | 把第 2 套改成高腰，减少装饰 |
| 保留并重抽 | 保留第 2 套，重抽其他 |
| 正背展示 | 把这套做成正背双视图 |
| 拆成部件 | 把这套做成部件拆解板 |
| 直接出图 | 直接生成第 2 套图片 |

只要可复制文本时，加上「只要提示词，不要解释」；反推仍给两版，单版可指定「只要陈列版」或「只要拆解版」。图片反推需要宿主具备图片理解能力；直接出图需要可用的图像生成工具。

## 默认设置

- **对象与风格**：18 岁以上成年女款、华丽幻想方向。男款、中性、日常、简约或竞技用途可明确指定。
- **数量**：原创默认 3 套；反推和精修默认 1 套。连续修改沿用已有方案范围，用户指定数量时优先。
- **展示**：无人物、无衣架；整套陈列用纯白摄影棚背景，浅色衣物需要护边时用珍珠浅灰；拆解板用浅中性灰。人物上身、黑底、多视图或统一构图需明确说明。

每套提示词可独立复制。用户要求优先于默认设置，详细规则见 [SKILL.md](SKILL.md)。

## 安装与更新

将 `<AGENT_SKILLS_DIR>` 替换为宿主的技能目录：

```bash
git clone https://github.com/splexuan/outfit-prompt-generator-skill.git <AGENT_SKILLS_DIR>/outfit-prompt-generator
```

也可下载仓库 ZIP，将完整文件夹放入技能目录。请保留 `references/`，不要只复制 `SKILL.md`，然后按宿主方式加载或刷新技能。

Git 安装的更新方式：

```bash
git -C <AGENT_SKILLS_DIR>/outfit-prompt-generator pull --ff-only
```

手动安装则重新下载并替换完整文件夹，先保留自己的本地修改。
