# 穿搭提示词生成器（Outfit Prompt Generator）

一个面向图像生成的中文 Codex Skill。输入服装品类、风格、场景或已有设计，即可得到结构成立、可直接复制使用、并可继续迭代的服装与穿搭出图提示词。

## 能做什么

- 对短品类输入生成 3–5 套差异明显的原创方案
- 支持女装、男装、泳装、内衣、运动、礼服与明确形制的传统服饰
- 根据商品图、真人画册、穿搭、设计稿、正背面或三视图调整展示方式
- 兼顾服装结构、材质逻辑、覆盖与支撑需求，以及商业化审美
- 支持连续修改，例如“保留第 2 套并重抽其余”或“全部改成高腰”

## 安装

将本仓库目录复制到 Codex 的 skills 目录，确保 `SKILL.md` 位于技能目录根部。随后可在对话中使用：

```text
$outfit-prompt-generator 夏日泳装
```

也可直接描述需求，例如：

```text
粉色系泳衣｜女款｜4套｜度假｜商品图｜详细版
```

## 目录

- `SKILL.md`：技能主说明与生成规则
- `agents/openai.yaml`：Codex 展示与默认提示配置
- `references/`：女装、男装、专项服饰、设计元素、商业审美与测试用例
